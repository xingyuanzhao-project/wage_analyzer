# Wage Explorer

Find the U.S. prevailing wage for any job, by state and county.

**Use it:** https://xingyuanzhao-project.github.io/wage-explorer/

## How to use it

- Enter a job title or keyword, plus a state and county.
- Review matching occupations, each with four wage levels (entry to expert).
- Expand a result for full job detail — tasks, skills, education.
- Select multiple roles and compile one combined report across them.

## Data sources

- **Wages** — U.S. Department of Labor, Office of Foreign Labor Certification (OFLC),
  Prevailing Wage data, Wage Year 2025-26 (Revised, effective 8/1/25).
- **Job detail** — O*NET 30.3 Database, USDOL/ETA, used under
